# Experiments Directory
## Smart Digital Stethoscope: Heart Sound Acquisition, Signal Processing and Quality Assessment
### EEE495 / EEE496 Senior Design Project (Platform / Software Codename: `AuscultaForge`)

This directory stores offline analysis configurations, acoustic comparison experiments, and validation logs.

---

## Guidelines
- Do not commit large generated binaries, recordings, or output artifacts to version control (`experiments/output/`, `experiments/cache/`, `experiments/sessions/` are ignored by `.gitignore`).
- Document experiment goals, hypotheses, and conclusions in Markdown alongside scripts.
- Physical characterisation measurement reports must be reproducible by scripts.
