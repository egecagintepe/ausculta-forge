# AuscultaForge Murmur MIL v1 — Research Only

Patient-level multi-recording model on CirCor public training subset.
No clinical diagnosis, no arrhythmia diagnosis, no extrapolation to ESP32/phantom.

Train/validation/internal test groups frozen using Additional ID links.
Validation threshold: 0.520. Best epoch: 6.
Limitations: pediatric population, single dataset, unknown labels excluded, unseen hardware domain shift.
