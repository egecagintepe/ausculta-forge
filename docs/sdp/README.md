## Canonical File Naming Convention

All deliverable files must follow this pattern:

```
WXX_<ModuleLetter>_<short-description>_vNN.<ext>
```

| Token | Meaning |
|---|---|
| `WXX` | Week number, zero-padded (e.g. `W03`, `W12`) |
| `<ModuleLetter>` | `A`, `B`, or `C` |
| `<short-description>` | Lowercase, hyphen-separated description |
| `vNN` | Version number, zero-padded (e.g. `v01`, `v02`) |
| `.<ext>` | `.pdf`, `.docx`, `.xlsx`, `.md`, etc. |

**Examples:**

- `W03_A_transducer-candidate-selection_v01.pdf`
- `W03_B_device-to-host-frame-draft_v01.docx`
- `W03_C_quality-metrics-validation_v01.md`
