## 1. Core Principles

1. **Hypothesis vs. Confirmed Cause:** A detection condition establishes an *observation*. Possible root causes are strictly classified as *hypotheses* until proven by physical probe/multimeter/telemetry measurement.
2. **Operational Severity vs. Diagnostic Certainty:** Severity (`DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`) measures the impact on clinical workstation operation, not the certainty of the underlying hardware diagnosis.
3. **Evidence Origin Demarcation:** Every diagnostic event records its source:
   - `OBSERVED_HOST`: Direct measurement by host operating system or transport driver.
   - `REPORTED_BY_FIRMWARE`: Numeric code or counter transmitted by microcontroller.
   - `DERIVED_FROM_SAMPLES`: Mathematical analysis of acoustic sample data.
   - `INFERRED_HYPOTHESIS`: Unproven diagnostic correlation rule output.
   - `INJECTED_SIMULATION`: Generated by Virtual Bench or synthetic test double.
   - `NOT_MEASURED`: Sensor uncalibrated or physical metric unobserved.
4. **Physical G1 Demarcation:** Each fault definition indicates whether it invalidates Phase-1 G1 hardware bring-up acceptance.

## 3. Subsystem Detailed Catalogs

### 3.1 Hardware Discovery & USB (AF-USB-xxx)

#### `AF-USB-001` — `NO_COMPATIBLE_DEVICE_DETECTED`
- **Detection Condition:** System serial port scan finds zero devices matching AuscultaForge ESP32-S3 descriptors.
- **Hypotheses:**
  1. USB cable lacks D+/D- data lines (charge-only cable).
  2. Cable connected to auxiliary UART connector instead of Native USB-OTG port (GPIO19/20).
  3. Microcontroller board unpowered or held in bootloader / reset.
  4. CDC-ACM driver missing in operating system.
- **Troubleshooting Steps:**
  - Verify USB cable data capability with a known peripheral.
  - Connect to the Native USB port directly.
  - Inspect Device Manager (Windows) or `lsusb` / `dmesg` (Linux).
- **Turkish Summary:** Ana bilgisayar USB veriyolunda AuscultaForge ESP32-S3 probu tespit edilemedi.

#### `AF-USB-002` — `PORT_ACCESS_DENIED_OR_BUSY`
- **Detection Condition:** OS returns `PermissionError` (EACCES / code 5 or 13) when attempting to open serial port.
- **Hypotheses:**
  1. Port is locked by another process (Arduino IDE serial monitor, PuTTY, minicom, ESP-IDF monitor).
  2. User lacks dialout group permissions on Linux.
  3. Orphaned AuscultaForge process holding port handle.
- **Troubleshooting Steps:**
  - Terminate competing terminal monitors.
  - Add user to `dialout` group on Linux (`sudo usermod -a -G dialout $USER`).
  - Restart backend server.
- **Turkish Summary:** Hedef seri port başka bir işlem tarafından kilitlendiği için erişim reddedildi.

### 3.2 Canonical B/C Protocol v0.1 (AF-PRT-xxx)

#### `AF-PRT-002` — `CRC_MISMATCH`
- **Detection Condition:** IEEE 802.3 CRC-32 computed on bytes 0..35 of header + payload does not match received 4-byte CRC trailer.
- **Hypotheses:**
  1. Firmware calculated CRC over incorrect byte range (must exclude bytes 36..39).
  2. CRC-32 polynomial or seed discrepancy (canonical: poly `0xEDB88320`, init `0xFFFFFFFF`, final XOR `0xFFFFFFFF`).
  3. Electrical signal noise corrupted bits on USB cable.
- **Canonical Test Vector:** `"123456789"` $\to$ `0xCBF43926`.
- **Turkish Summary:** Paket CRC-32 bütünlük doğrulaması başarısız; veri bozuk veya yanlış hesaplanmış.

#### `AF-PRT-004` — `HELLO_NONCE_MISMATCH`
- **Detection Condition:** `hello_ack.nonce != hello_req.nonce`.
- **Hypotheses:**
  1. Firmware hardcoded a constant nonce instead of echoing the request nonce.
  2. Stale response received from prior discarded handshake attempt.
- **Troubleshooting Steps:**
  - Ensure firmware executes `ack.nonce = req.nonce`.
  - Flush input buffer before sending `HELLO`.
- **Turkish Summary:** HELLO el sıkışması nonce uyuşmazlığı; cihaz yanlış veya eski işlem anahtarı döndürdü.

### 3.3 Streaming Integrity & Telemetry (AF-STR-xxx)

#### `AF-STR-001` — `FRAME_SEQUENCE_GAP`
- **Detection Condition:** Audio frame `sequence_id > expected_sequence_id`.
- **Hypotheses:**
  1. Microcontroller dropped frame due to internal buffer saturation.
  2. USB bulk transfer dropped in operating system stack.
  3. Host process descheduled.
- **Troubleshooting Steps:**
  - Reconcile with `STOP_ACK` telemetry (`dropped_samples`, `usb_partial_write_events`).
  - Increase microcontroller ring buffer size in PSRAM.
- **Turkish Summary:** Ses çerçevesi sıra atlaması tespit edildi; bir veya daha fazla USB paketi kayboldu.

#### `AF-STR-009` — `G1_SAMPLE_MISMATCH`
- **Detection Condition:** Decoded sample $x[n] \ne (n \times 37) \pmod{2^{24}}$.
- **Hypotheses:**
  1. Endianness mismatch in 24-bit Little-Endian unpacking.
  2. Sign-extension bit error.
  3. Microcontroller generator formula mismatch.
- **Turkish Summary:** Fiziksel G1 kabul testi başarısız: çözümlenen örnek değeri referanstan farklı.

### 3.4 Signal Quality & Acoustic Diagnostics (AF-SIG-xxx)

#### `AF-SIG-001` — `NEAR_SILENCE_DETECTED`
- **Detection Condition:** Signal RMS $< -60\text{ dBFS}$ for $\ge 2.0\text{ s}$.
- **Hypotheses:**
  1. I2S microphone (INMP441 / PUI) unpowered or data line (SD) disconnected.
  2. Clock lines (BCLK / WS) floating.
  3. Synthetic test generator producing zeros.
- **Constraint:** Does **NOT** prove physical sensor destruction without hardware multimeter/oscilloscope check.
- **Turkish Summary:** Sinyal neredeyse tamamen sessiz; akustik enerji beklenen taban gürültüsünün altında.

#### `AF-SIG-002` — `CLIPPING_DETECTED`
- **Detection Condition:** Sample absolute amplitude $\ge 0.999\text{ FS}$ for $> 0.1\%$ of window.
- **Hypotheses:**
  1. Excessive acoustic sound pressure or direct mechanical tapping on diaphragm.
  2. Firmware arithmetic gain overflow.
- **Turkish Summary:** Dijital sınır kırpılması tespit edildi; örnekler tam ölçek tavanına ulaşıyor.
